# Домашнее задание: Работа с регулярными выражениями

## Описание
Проект для работы с банковскими транзакциями, использующий регулярные выражения для поиска по описанию и подсчета операций по категориям.

## Функциональность
- `search_transactions()` — поиск транзакций по строке в описании (с использованием `re`)
- `count_operations_by_category()` — подсчет операций по категориям
- `main()` — консольный интерфейс для работы с транзакциями

## Установка
1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать: `venv\Scripts\activate` (Windows)
3. Установить зависимости: `pip install -r requirements.txt`
